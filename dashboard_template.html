Two recorded flood seasons, rainfall trigger vs. discharge response
Threshold method. Annual maximum daily discharge for each of the 36 years (1990–2025) was ranked and fit to a Gumbel (Extreme Value Type I) distribution using the reduced-variate linear regression Q = a·y + b, the same method already used for the project's rainfall frequency analysis. Advisory/Watch/Warning/Severe map to the 2/5/10/25-year return-period discharges from that fit. Rainfall trigger. For the 2012 and 2022 case studies, the trigger time is the most recent point before the discharge peak at which trailing 24-hour rainfall reached 20 mm — a standard heavy-rainfall threshold — used here as a stand-in for a forecast/nowcast rainfall alert. Scope. Built on the historical record only; no live or forecast feed is connected. Episode detection merges exceedance days separated by a single dry day into one continuous episode.
